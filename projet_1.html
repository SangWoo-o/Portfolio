Mechatronics Project: Walking Quadruped Robot

During my second year at ELISA, I designed and fabricated with my team a walking quadruped robot. The goal of this project was to design and fabricate an autonomous quadruped robot capable of walking. The project features 3D CAD modeling of custom adaptation components, a regulated power supply system, and a static balancing algorithm written in Arduino C++.

Arduino C++ 3DExperience CAD PLA 3D Printing
01 INITIAL STAGES

CAD Architecture and Assembly

In this first stage of the project, we analyzed how and why the quadruped design would work, established a complete list of all required components, and set up a project timeline to ensure everything was ready on time.

  • Mechanical Analysis: Drafted a numerical analysis report evaluating key mechanical and physical constraints.
  • 3D CAD Adaptations: 3D-printed main chassis and 4 articulated legs using PLA. Designed custom mounting plates in 3DExperience to fit an Arduino Nano onto a chassis intended for an Arduino Mega and a bearing spacer. Integrated ON/OFF switch housing.
  • Physical Robot Assembly: Personally assembled the physical quadruped structure, fitting the 3D-printed PLA frame, articulated leg linkages, joint pins, and servomotors.
02 Second stage of the project

Electronics & Component Integration

During this second phase, the main challenge was understanding how each component functioned and mastering precise soldering techniques to avoid damaging sensitive electronics. Through hard work and careful testing, we successfully completed the electronic integration.

  • Power Management: Helped to map out the full wiring diagram, defining pin allocations for power rails (VCC 5V, GND).
  • Sensors & Wiring: Hand-soldered power distribution rails, custom breadboard cabling, battery switch connections, and expansion board headers.
03 Last stage

ROBOT PROGRAMMING

As we entered the final programming phase, we developed the control algorithms for static balancing and gait execution in Arduino C++, integrating IMU sensor feedback to keep the robot stable during locomotion.

  • Mass Transfer: Assisted in developing the program CoM balance routines to keep the robot stable while walking.
  • Arduino C++ Firmware: Co-developed control algorithms for servo angle transformation matrices, joint limit constraints, and gait timing cycles.

What I Learned

  • CAD:Learned to quickly adapt under tight deadlines by diagnosing root problems and evaluating multiple design options. Realized the practical impact of theoretical physics, reinforcing the importance of thorough upfront mechanical analysis before launching CAD modeling
  • Structure:I realized the importance of good communication and task distribution within the team, which creates a positive environment and maintains a steady work cadence.
